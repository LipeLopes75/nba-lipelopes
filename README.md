# Lipe Lopes NBA — Comunidade

Código original da página https://lipe-lopes-nba-comunidade.aguiar-phillipe.chatgpt.site/.

Site estático em HTML/CSS, com imagens e fontes em `dist/assets/`.

## Executar localmente

```sh
python3 -m http.server 8000 --directory dist
```

Abra http://localhost:8000. Não é necessária uma etapa de build. Para hospedagem estática, use `dist` como diretório de publicação.

Importado da versão 8 do Sites (commit de origem `c5b8dcbbbfd1fa6967019c3cc0b861b1838b6929`).
